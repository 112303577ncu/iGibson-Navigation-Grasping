# 兩張定位標記的放置規劃

同頁列印請使用專案根目錄 `output/pdf/aruco_120mm_A4_two_markers.pdf`：單張A4、上下各一個120mm黑框，ID0／1。尺寸與解碼驗證見[列印檢查](PRINT_REVIEW_2026-10-17.md)。以下160×180mm與20mm白邊指單張SVG來源；同頁PDF的上下白邊18.5mm、兩黑框間21mm。

使用 OpenCV DICT_4X4_50，ID 0 與 ID 1。SVG 實體尺寸160×180mm，黑色方框120×120mm，四周白邊至少20mm。列印100%，不要縮放符合頁面；印完量黑框邊長，實際值才是程式markerLength。圖案已由OpenCV生成並以相同字典解碼驗證；尚未完成實體列印/相機距離驗收。

- ID 0：投放紙盒旁的固定硬支架，朝場地中央；避開紙盒開口和手臂投放掃掠範圍。
- ID 1：紙盒對角、主巡航點後方的固定硬支架，朝場地中央／投放區。
- 標記保持直立，中心先放在廣視野相機鏡頭約同高處；支架不要隨軟牆彎曲，也不要侵入原巡航通道。相機畫面確認可見後才固定。
- 量測兩張標記相對固定場地基準的位置、朝向，以及標記相對紙盒的位置；不能只憑照片猜map座標。
- 兩張是起始配置，不保證全場每個位置/朝向均可見。實測遮擋後才決定是否加第三張；暫時看不到時使用既有odom/LiDAR，不能假裝marker定位有效。

標記尚未接入導航或AMCL。正式啟用前要驗證目前廣視野相機的內參、畸變、相機到車體外參；對視覺位姿做多幀品質與一致性檢查，再在停穩時校正，避免單幀跳點直接改車體座標。
