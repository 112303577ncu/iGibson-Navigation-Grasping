# 紙盒移入場內後的重新標定

使用者確認紙盒仍在原角落，18cm長邊平行原後牆，紙盒外緣距後牆/左牆均約20–25cm；軟牆形狀造成誤差。舊紙盒pose、停靠點及盒子keepout不再代表當前擺位，scene_layout已標pose_map_valid_for_current_placement=false與navigation_mask_valid_for_current_bin_placement=false，局部30cm候選仍未啟用。

以22.5cm中點和舊照片角落對應只生成候選map(1.55994,0.83333,yaw1.12099)。兩個牆距範圍本身帶來約3.54cm二維位置範圍半徑，還未包括牆形、定位及角落對應誤差；沒有覆寫成已註冊目標，也沒有依此移動。原有pose/footprint保留作歷史，重建約束前不可使用。

實機owner27713未變、odom未移動、輪零/maintenance=true/travel。用舊seed加LiDAR13→10cm的純幾何位移作讀取定位初值，在新10cm TF下重新啟動AMCL，唯讀probe ok=true、pulses=0、scan age0.156秒、TF新鮮。估計map(1.33361,0.80818,0.20377)，位置標準差約8.1/8.7cm；僅靜止啟動/資料檢查，不是位置準確度、移動相容性或投放驗收。暫時AMCL已停止。

後RGB新圖中沒有完整紙盒，近車區被機構/畫面邊緣遮擋；不能從這張圖可靠找盒子中心。已請使用者重新量移盒後車體前緣至盒近緣距離，以及盒中心相對車頭左右角度。移盒前30cm/左20°不能沿用。下一步以新量測核對實體對照，再建立新盒緩衝/停靠朝向，確認空夾爪可達後測退出與返回巡航。

新增require_motion_ready：即使日後10cm幾何驗證通過，盒子已搬動而遮罩未重建仍拒絕實車巡航/停靠。相關58項離線通過。證據docs/calibration/box_reposition_2026-10-17/。本輪未推送GitHub。

最新現場回覆：對準需右轉約30°，操作者確認目前距離可直接放置，接受此距離判斷，不再追問數字；尚未執行轉向或放置。正式release只會向前伸出且會拒絕空夾爪，不能把它當空夾爪預演。原始程式bin_rim_height預設5cm而現盒高6cm，後續須核對/同步常駐設定，不能只根據距離足夠宣稱投放通過。
