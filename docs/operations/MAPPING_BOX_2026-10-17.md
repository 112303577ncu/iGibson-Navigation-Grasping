# 紙盒投放場地建圖與任務設定

## 正式流程

巡航 → 辨識待夾物 → 接近/E1交接 → 夾取確認 → 收臂 → 導航到紙盒停靠點 → 投放 → 收臂 → 回到巡航。投放點不是紅色桶子。

沿用v23常駐owner，禁止另開Serial寫入者。AMCL、新路線、接近/夾取/投放交接均須各自驗證，不能將這些缺口全部描述為已完成後只剩流程優化。結果未知的grasp/release不重播，持物狀態未確認不可當作已投放後接續巡航。

## 地圖、限制圖與紙盒

資料在 maps/demo_box_20261017/。牆線估計1.978×2.022m。仍有局部重影/缺口，原圖未補牆。生成的獨立中心限制圖要求：已知空地、距occupied≥40cm、且距擬合四牆≥40cm。巡航候選取50cm牆內縮，404點最小實際occupied中心距42.05cm。

這些是準備完成的導航資料，尚未接入runtime，不能宣稱禁航區已生效。不得將內縮40cm的中心限制圖提供給AMCL，避免把實際牆位置改掉。

室內occupied連通群聚在距牆12cm以內者排除後，無可確認紙盒的群聚。這不證明紙盒不存在或一定低於9.5cm雷射；需要長寬高、兩面牆到盒緣距離與角落對應確認。已向使用者請求量測，未得到數據前不填任意投放座標。

## 新圖AMCL靜止檢查

先停止GMapping，再以原圖啟動獨立map_server+AMCL，有90秒外層上限、768MB虛擬記憶體上限；沒有任何底盤動作。初始pose由剛才GMapping提供，位置方差先驗0.01m²、yaw方差0.0076rad²，300..1000 particles、60 beams。

5次request_nomotion_update均得到新鮮amcl_pose：位置約(-0.0679..-0.0748,0.3034..0.3049)m、yaw -19.79..-19.64°；最後var x/y約0.00607/0.00506m²，yaw約14.268deg²。可確認新圖/scan/TF與定位入口可運行；不是無先驗冷啟動定位、移動定位、精度或重定位驗收。沒有把低變動當成實際尺量精度。

AMCL試驗已停止，vision與monitor已恢復。RAM快照建圖中1808MB、停止後1935MB，非全程最低值。原始報告與launch在docs/calibration/mapping_box_2026-10-17/。
