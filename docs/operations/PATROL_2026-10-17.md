# 紙盒對角巡航與移動定位驗證

## 結果與適用範圍

約2×2m、固定紙盒場地，已完成兩次有界監督式逆時鐘巡航，實際移動使用AMCL map定位、原生ROS scan/odom、唯一常駐grasp-service TCP7000。不是只按時間轉圈，也不是僅靜態路線通過。

巡航主點是紙盒角落的對角內縮點：map(0.10093,0.30826)m。路線距擬合牆60cm，經四點返回主點；結束朝場內。40cm中心禁航遮罩及實測紙盒緩衝保持，60cm是選點餘量，不是把禁航距離改為60cm。照片→紙盒map角落仍是既有對應假設，未有實體地標測量。

| 第1圈 | 暫停 | 主點+四段均完成 | 6.65–8.67cm | 0 |

第2圈轉向面向場內後的主點誤差8.91cm、朝向誤差約4.00°。數值是AMCL融合odom估計，不是尺量實際精度。第一版試跑尚未加最後面向場內和全程RAM最小值欄位；第2圈使用最終版本。兩圈owner均PID27713，未重啟/未另開Serial，最後零輪、maintenance=true、巡航位、空夾爪。

第2圈每次控制狀態檢查取MemAvailable，最低1593.90MB。第1圈只有RAM快照、最小值記為null，不能把第二圈最低值套用到第一圈。記錄的停穩樣本103/125筆都在限制圖內，最近occupied距40.25/52.80cm；最大scan stamp年齡0.211/0.227秒。這些是停穩樣本統計，不冒充整個運動期連續記錄；每次速度寫入前仍執行即時感測與限制圖檢查。

## 入口與控制限制

- `deploy/ros/g2_map_patrol.py`：ROS Melodic `/usr/bin/python`；不載入模型、不開Serial。原生訂閱scan/odom/AMCL並透過map←odom融合即時位姿，0.5秒請求一次nomotion更新，避免靜止AMCL被誤判過期。
- `integration/g2_patrol_policy.py`：讀獨立中心限制圖。目標線段、中途當前位置、預計停止路徑、轉向6cm中心漂移預留均檢查；禁入紙盒。只是此導航入口的檢查，未在常駐TCP內對其他client全域攔截。
- 線速度命令0.15、轉向命令±1，以有界脈衝搭配停穩回授，不使用低於啟動門檻的連續微速。平移上限按0.35m/s保守估計，停止路徑另留15cm；直行牆面煞車中心距50cm不放寬。
- scan到達≤0.35s、odom到達≤0.20s、兩者stamp≤0.40s；AMCL資料≤2s、TF age -0.6..1s（AMCL有未來容忍）；位置標準差≤15cm、yaw≤10°。當前中心違反遮罩、owner變更、手臂非travel、板回傳過期、RAM<768MB停止。
- 短暫資料過期先停車，最多3秒等待、每次執行最多12次恢復。此兩圈沒有實際觸發恢復，不能當作故障注入驗收。目標每段≤150秒，執行≤600秒、最多2圈；systemd外層有時限，SIGTERM進finally停輪/斷開TCP/上鎖。結果未知的夾取/投放從未重播。
- 初始停靠點靠近40cm遮罩邊時，只允許朝主點方向、且預計停止路徑合法的有限前進進入轉向餘量，再旋轉。禁止從邊界盲轉/倒車。
- 第2圈最後朝向場內，是為後續觀測/辨識準備；不代表已接通視覺接近、夾取或投放。

## 定位生命週期與重現

兩圈共用同一AMCL會話，先前GMapping已停止。試驗後AMCL暫時服務已停，vision/monitor維持active，機器保持開機。下一次執行需重新啟動定位，不能把過期TF當作ready。

`deploy/ros/g2_scene_localization.launch`提供同一組測試參數的可重用入口，初始map pose必填；不要給AMCL使用navigation_center_mask。`last_pose_seed.json`只在車未搬動、版本/參考仍有效時可作種子，不是冷啟動定位驗收。啟動前確認沒有另一個GMapping/AMCL發布map→odom，並套用有界runtime及RAM限制。

```bash
source /opt/ros/melodic/setup.bash
export ROS_MASTER_URI=http://127.0.0.1:11311 ROS_IP=127.0.0.1
# x/y/yaw 必須換成當前合理的map參考；launch不預填0來假裝定位。
roslaunch deploy/ros/g2_scene_localization.launch initial_x:=0.12538 initial_y:=0.39396 initial_yaw:=0.15491
# 另個已source ROS的終端，先唯讀確認；scene路徑必須對應當前原始定位圖。
/usr/bin/python deploy/ros/g2_map_patrol.py --scene maps/demo_box_20261017 --output /tmp/patrol_probe.json
# 真機仍走常駐owner；最多一圈300秒，完成後鎖回maintenance。
/usr/bin/python deploy/ros/g2_map_patrol.py --scene maps/demo_box_20261017 --real --loops 1 --seconds 300 --output /tmp/patrol_result.json
```

這是可重用的獨立監督式導航入口，尚未接到`grasp/v23/demo.py`的完整任務plan，後者原有home/grasp/stow/release/短直線能力不因此自動變成完整決賽主線。
