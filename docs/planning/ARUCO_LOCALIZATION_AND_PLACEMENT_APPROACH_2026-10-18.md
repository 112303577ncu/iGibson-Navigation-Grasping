# ArUco 定位與投放盒視覺接近規畫

## 決策

交件前保留 AMCL 作地圖導航，以已登錄 ArUco 提供絕對方向／初始位置及必要重定位；紙盒最後靠近改用相對視覺。不是貼完標記就能刪除 AMCL。ArUco-only 系統可另外實作，但仍需相機內外參、標記 map 位姿、遮擋處理、odom 連續追蹤、不確定度及定位輸出介面，並非現有系統的一個開關。

本輪8張標記成功解碼，只代表看得到；尚未完成量測定位與自動融合。貼在軟牆上的標記若會隨牆彎曲／移位，其 map 錨點也會改變。至少定位基準及投放區參考須固定在硬背板／穩定支架，或重新量測登錄。

## 「AMCL 過期」的區別與改善

1. AMCL 不是固定運行幾分鐘就會到期。舊診斷單元的40分鐘期限已移除；不要重新用它作展示入口。
2. 初始化／重啟參考與即時 scan／odom／TF 是不同時效。本輪已修正新外部參考120秒、啟動卻只允許15秒的不一致；健康 AMCL 回復種子維持15秒，正常運行持續更新，不是每15秒重定位。
3. 目前掃描／TF不新鮮、濾波器未發布、程序退出及被搬車都可能表現為定位不可用，應各自記錄原因，不全部標示 AMCL timeout。
4. 搬運不一定改變輪式 odom，AMCL covariance 小也不代表角落正確。每次未知起點先用已登錄標記建立一致位置，再檢查 LiDAR／地圖吻合度；有歧義就有界搜尋，不沿用關機或搬運前種子。
5. 短暫資料延遲先暫停地圖導航並等待新幀，避免立即重啟健康 AMCL；持續故障才使用既有有限重啟。不要只把所有 freshness 門檻放大，讓舊資料看似正常。
6. 分階段要求定位：巡航／跨場導航需要可靠 map 定位；已進入驗證過停靠走廊、紙盒相對視覺與 odom／LiDAR 正常時，可由局部接近接手，AMCL 短缺不應直接視為紙盒消失。這項降級仍需新增狀態與實測，目前 v23_dock_approach 的 guard 仍硬性要求 AMCL ready，尚未變更。
7. 未登錄的標記不能僅靠ID推算公尺位置；登錄後由單一定位管理者決定何時送 initialpose 或融合校正，避免 ArUco 與 AMCL 同時競爭發布 map→odom。

## 為何目前準備區距離仍有落差

地圖只提供大致到點，盒位尚未完整登錄，AMCL也有數公分級估計變動。現在準備區不保證在組員辨識器的可鎖定範圍內；若盒子已太近或偏出視野，接近程式根本無法取得初始目標。交接點必須由持物姿態下的實際可視範圍決定，面向紙盒，不能再以固定「補前進30cm」收尾。

停止目標應是**投放時夾爪落點對準盒內可用區**。先 release-preview 標記落點，以四輪中心量 x／y；再量盒口內尺寸、物體尺寸，以及實際靠近方向的盒深。若正對盒的一側，視覺量的是近緣，近緣目標距離約等於「實測放開落點x − 該方向盒深的一半」。斜向接近需先轉正或估計盒姿態，不能永遠減13.5cm的一半。頁面上的FK數字只是起始估計，不作正式停止值。

後相機若在約0.64m就失去盒子，而近緣停止目標約0.2m，會有約40cm量級的不可見區間，不能稱為短短幾公分補進。優先調整可視角度、使用另一可見相機或與盒口固定關係的專用標記維持觀測；確實做不到，才以已鎖定目標的odom傳播作有限收尾，限制距離、時間、左右與角度誤差，回報「推算」而非「當前影像量測」。以盒口18×13.5cm考量，頁面聲稱的±4cm前後誤差不能直接視為投放必定成功，還要扣除物體尺寸和左右誤差。

## 執行順序與驗收

1. **取得模型與校正來源**：放置盒best.pt、完整hash、class名稱／index、實際後相機640×480設定，核對camera→base原點。先用本輪保存影像做離線辨識，包含車身、夾持物與場外桶／盒的負樣本。桌機跑YOLO/SAM，Jetson保留RAM閘。
2. **量投放落點**：下一次開機做空爪release-preview，標地面落點並量到車體中心x/y；這是必要測量。由組員確認實際持物release姿態及內部可用盒口，再產生placement profile。
3. **不動車驗證**：在實測可見範圍記錄不同距離、角度與持物狀態的盒近緣座標、置信度、相機延遲、遮擋起點；以尺核對，同時完成至少必要ArUco內外參／map錨點登錄。一次成功畫框不算metric校正。
4. **修交接點與單一控制權**：地圖導航到能看清紙盒的位置與朝向→停車／釋放TCP→後相機目標多幀鎖定→組員同一接近控制器接手。近盒走廊按實體幾何驗證，保留牆界，不整體放寬40cm或全場禁航區。
5. **空爪接近／預演**：較遠先對準，逐段接近，每段用新影像或明確標示的有限odom傳播更新。實測停止後release-preview落點應在盒內可用區，不以AMCL到點誤差驗收。失去相機／目標先停等再有界重取，不直接重播上次速度。
6. **連續驗證**：至少三個不同起點各做一次空爪預演；再與組員作三次持物「夾取→stow→地圖到可視交接點→視覺靠近→release確認→stow→退出→續巡航」。release只執行一次，以狀態／操作ID判斷結果，斷線不能自動再放一次。
7. **PPO後置**：先取得可重複的紙盒接近與停止幾何，再在相同資料做PPO影子比較與接管驗收。不要同時更換全域定位、PPO與投放幾何而無法判斷誤差來源。

本文件是讀取實際交接頁與本機程式後的執行規畫，尚未新增placement執行模式、取得專用權重或啟用視覺投放。機器已按使用者要求關機；本輪後半只做離線讀取與規畫。
