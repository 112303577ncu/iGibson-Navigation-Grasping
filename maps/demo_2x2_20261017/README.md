# 2×2m 場地掃描圖與逆時鐘巡航候選

`demo_2x2.yaml`可供map_server讀取，解析度2cm。原始SLAM圖保留角落缺口與向外射線。

`patrol_candidate.json`的點位在map座標、由實際監督式繞行停車點轉換；404個中心取樣均已知空地，最小障礙中心距38cm。藍色虛線是**候選**，尚未驗證AMCL與自主巡航。

正式使用前需統一導航client雷射前13cm、設定獨立禁行邊界避免穿出角落、驗證完整車體/停止包絡及實際重複巡航。勿修改原始圖假裝缺口是實牆。

結果與限制見[現場操作紀錄](../../docs/operations/MAPPING_LOOP_2026-10-17.md)。
