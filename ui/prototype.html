操作步驟

從開機到機器人開始工作，一共四步。前兩步只在第一次或換網路時需要。

  1. 開啟機器人電源，等待桌面出現連線 QR code
    機器人每次開機會偵測目前的 IP 並重新產生 QR code，所以換了網路也不用手動查。
  2. 用手機掃描 QR code
    會直接開啟這個頁面並自動填入 IP。掃到的是舊的 QR code 也沒關係，在上方手動改就好。
  3. 在「出發前檢查」確認 15 項狀態
    相機、伺服機、定位、權重指紋逐項檢查。有紅燈就不要出發。
  4. 選擇執行方式，按下開始
    之後全程看主控台就好。要停下來隨時按右上角的停止鈕。
